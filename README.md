## Descripción

Este repositorio contiene mi práctica de *Markdown* utilizando *Visual Studio Code* y Git.

## Pasos para subir un cambio a GitHub

1. Modificar los archivos necesarios.
2. Guardar los cambios.
3. Comprobar el estado con `git status`.
4. Añadir los cambios con `git add .`
5. Crear un commit con `git commit -m "Actualiza README"`.
6. Subir los cambios con `git push`.

## Comandos utilizados hoy

| Comando | Qué hace |
|---|---|
| `git status` | Muestra el estado del repositorio |
| `git add .` | Añade los cambios |
| `git commit -m "mensaje"` | Crea un commit |
| `git push` | Sube los cambios a GitHub |
| `git pull` | Descarga los últimos cambios |

## Incidencias

Durante la práctica tuve un problema con *fatal: The current branch main has no upstream branch.*

El problema ocurrió porque *No tenia vinculado el git con el github*.

Lo solucioné haciendo *Viculando con el comando gti push --set-upstream origi main*.
